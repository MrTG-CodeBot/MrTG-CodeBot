### 🎮 The Senior 3D Experience Architecture

Engineered with modular, game-engine-inspired Three.js class systems:
- **Hero Flight & Physics**: Scrolling the mouse wheel (or dragging on mobile) pilots the camera along a 3D spline curve. Spider-Man dynamically banks, bobs, and slings dual red 3D kinetic web lines into passing skyscrapers.
- **Click Acrobatics**: Click Spider-Man anywhere on screen to trigger a dynamic 360° corkscrew flip with procedural sound synthesis and the `BOOM-WEB!` comic blast.
- **Architectural Drafting Sky City**: 90+ procedural cel-shaded skyscrapers with ink wireframe contours, flashing red safety beacons, and floating CAD measurement rings.
- **Blueprint CAD Specs**: Live 3D screen-projected technical annotation pins tracking Spider-Man in real time (Headphones, Hoodie, Backpack, Air Jordan 1s).
- **Procedural Web Audio Engine**: Zero-dependency audio synthesizer creating dynamic whip whooshes, harmonic sector chimes, and flight boosts with a global mute toggle.
- **Sectors**:
  1. `SPEC-01 // IDENTITY`: Studio Philosophy & Concurrency Architecture.
  2. `SPEC-02 // FLEET`: Autonomous Telegram Bot Fleet & Infrastructure.
  3. `SPEC-03 // ARSENAL`: Technical Full-Stack Matrix.
  4. `SPEC-04 // VELOCITY`: Real-time GitHub Activity Telemetry.
  5. `SPEC-05 // TRANSMIT`: Encrypted Direct Channels (Telegram, Discord, Email).

### 🌐 Live 3D Hosting via GitHub Pages

1. Navigate to: `https://github.com/MrTG-CodeBot/MrTG-CodeBot/settings/pages`
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Select `main` branch and `/ (root)` folder, then save.
4. Your live 3D studio will be accessible at:
   👉 **`https://mrtg-codebot.github.io/MrTG-CodeBot/portfolio/`**
